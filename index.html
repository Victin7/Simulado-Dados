Simulados de Banco de Dados

Três simulados para revisar a matéria: 8 questões objetivas com resposta na hora e 2 dissertativas com gabarito em cada um. As opções mudam de ordem a cada tentativa.

Questões dissertativas

Os exemplos usam um restaurante com as tabelas pedido, itens_pedido, produto e atendente. O gabarito das dissertativas traz os pontos que a resposta precisa ter, não um texto para decorar.
